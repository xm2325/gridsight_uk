# MPID direct material detector v1

29 August 2026. This is a bounded diagnostic, not a UK accuracy or production claim.

## Execution and data boundary

Roihu Slurm job **938745** completed with exit `0:0` in 1 minute 49 seconds. The CUDA pipeline used an NVIDIA GH200 120GB, PyTorch 2.10.0 and Ultralytics 8.4.48. Training was fixed before submission at two epochs, 640 pixels, batch 32 and seed 29. The final epoch was fixed as the checkpoint; neither UK images nor development metrics selected it.

The prepared MPID set contains 4,805 images after exact-byte deduplication and cross-material conflict quarantine: 4,335 train images and 470 filename-family-disjoint development images. The preparation collapsed 212 exact duplicate groups. One exact image appeared once under glass and once under composite; both copies were quarantined rather than choosing a label. MPID's flattened export does not retain authoritative upstream-source identities, so the split prevents known filename-family and exact-byte leakage but does not establish upstream-source independence.

## UK transfer outcome

The model was first run on eight source-described UK images while retaining all outputs down to raw detector score 0.05. The exact eight-record target manifest is preserved as `data/uk_material_eval_v1/mpid_run_uk_targets_v1.json` with SHA256 `b27b9d5d43ef323b7755640499337ebe8637883d451c9b675255c93f10a1a2a8`; the expandable acquisition pool now contains an additional prospective image. The outputs expose several domain-transfer failures:

- it detected only the glass side of mixed-material image 2952166 and missed the source-described ceramic side;
- it failed to recover the six existing source-assisted material boxes in image 8090535 and instead produced small glass-labelled boxes elsewhere;
- it split the complete glass string in image 3209028 into partial boxes and added a porcelain-labelled scaffolding region;
- it found partial regions of both porcelain strings in 3208894, at low raw scores;
- low-resolution glass image 3809215 was labelled composite, demonstrating why unresolved images need abstention;
- the clear ceramic pin insulators in auxiliary image 7880016 were labelled glass, including a raw score of 0.583;
- glass strings in 770248 received overlapping glass and composite labels, including nearly tied high-score fragments.

These are raw, uncalibrated detector outputs. Page text is material evidence; predictions never become truth.

## Prospective same-asset check

Image 770272 was acquired after the first UK inference. Its source page identifies the replacement string as porcelain. One complete-assembly box was manually frozen before inference on this image. Because sibling image 770248 had already been observed, this is prospective at image level but not independent at asset level.

Inference-only job **938791** completed with exit `0:0` in 10 seconds. A prediction overlapped the frozen complete-string box at IoU 0.504 but labelled it composite rather than porcelain. Its raw score was 0.071, so the fixed diagnostic gate returned `unknown`. A shorter partial box on the same porcelain string received composite score 0.730 and passed the per-box score/pixel gate. This is the decisive failure: confidence and native-pixel thresholds cannot determine whether a box covers the complete physical assembly.

## Architecture decision

The direct three-material detector is retained as an additional proposal generator, not promoted to the final material decision. The next implementation should:

1. union proposals from the UK-adapted material-agnostic detector and the MPID detector;
2. consolidate fragments into one physical assembly only when attachment geometry supports it;
3. classify both tight dielectric and contextual crops using a supervised glass / porcelain / composite head;
4. require crop agreement, native resolution, assembly completeness and target-calibrated acceptance;
5. output `unknown` when any gate fails;
6. freeze source-supported boxes on new independent UK asset groups before inference.

The verified English viewer is generated by `build_mpid_material_report.py` and served locally on port 8777. It displays raw predictions, source evidence, legacy references and the prospective frozen reference separately.
