Recommended CV pipeline

Image suitability → component detector → automatic instance crops → supervised material features with rejection → assembly relationships → asset aggregation when verified asset IDs exist.

Keep the current YOLO baseline. Use Grounding DINO to assist annotation, then compare frozen SigLIP2 features plus a small trained head against a joint material-aware detector after labels exist. Segment metal pixels if condition assessment is needed. Do not train from unchecked candidate labels.

Display evidence, not just colourful boxes

Retain class filters, original pixels, source credit and raw prediction links. Show component role separately from material; distinguish model proposals, reviewed annotations and derived regions. Include failure cases, native crop sizes and an explicit unknown state.

Evaluate localisation, material confusion, automatic-crop end-to-end performance and error versus rejection coverage separately. Do not convert cosine similarity into a percentage probability.

Experiment scope and evidence

Match the task to the data

Run and verified

  • Localisation Three-class supervised training against a fixed open-vocabulary baseline.
  • Source separation Train circuits 1/2/3/6, development circuit 4, evaluation circuits 5/7.
  • Traceability Original images, polygons, derived boxes, predictions and weight hashes retained.
  • Transfer audit All 27 UK photographs remain available, including failures.

Not established

  • Materials Independent material evidence and independent assets are still needed.
  • Structural detail Steelwork is not a synonym for crossarm. Pole-top needs a precise unit.
  • UK accuracy Viewpoints and scales differ; UK images lack reviewed references.
  • Safety No validated defect classes, risk ratings or maintenance advice.
Why was a glass / porcelain model not trained?

The verified official UVInsDet release has 591 images, but porcelain annotations occur in only one train image and one test image (11 / 12 boxes). They describe individual discs or sheds, not whole strings or mounted units. The facility layouts are also similar, without verified asset identities. This cannot establish independent UK whole-insulator material performance.

Original labels remain unchanged; polymer was not renamed porcelain. Label audit JSON · Two source images · Official release

Export all 27 UK annotation tasks, including the 20 images without supervised output at score 0.25. Add missing objects throughout each image. Experiment, metrics and data-use boundaries

40 epochs, 1280 input, batch 8, AdamW, FP32, seed 17. Checkpoint selection uses development data only. Evaluation thresholds were not tuned; old UK holdouts were not reused. Fixed baseline prompts: utility pole / crossarm / insulator. No prompt search on the new evaluation images.

Matches require the correct class and sufficient IoU. AP uses 101-point interpolation, IoU=.50:.95, all object sizes and at most 300 candidates per image. This is not the official EPRI leaderboard metric. The open-vocabulary base retains its segmentation architecture, but only boxes are scored; supervised adaptation uses a detection head.

Circuit groups come from publisher filenames; physical asset identities were not separately verified. Train/evaluation samples have no completely target-free images, so non-pole filtering is not validated. Public pretraining overlap is unknown. Class toggles only change the display, not image-level or aggregate metrics.
