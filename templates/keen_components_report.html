这次升级覆盖什么

任务与数据先对齐

已运行并验证

  • 部件定位 三类监督训练，原始开放词汇模型作对照。
  • 来源隔离 训练线路1/2/3/6，开发线路4，评估线路5/7。
  • 可追溯 原图、原始多边形、派生框、原始预测和权重哈希保留。
  • 迁移展示 27张英国原图，所有样本可查看，没有只保留成功例。

还不能声称完成

  • 材质 glass / porcelain / polymer 需要足够多独立资产的材质参考。
  • 杆顶与钢构 pole-top 需定义标注单位；steelwork 需要与横担形状分开的材质或部件标签。
  • 英国验证 地面远景与无人机近景有尺度和视角差异，目前英国样本没有GT。
  • 运行安全 没有缺陷标签，没有危险等级或维修建议。
为什么没有直接训练“玻璃 / 瓷”分支？

已下载并校验 UVInsDet 官方591张数据，但原始COCO中的瓷标注只来自训练1张图和测试1张图（11 / 12个框），且这些框是同一柱上的盘片/伞裙级区域。两张图的设施布局也十分接近，资产身份未核实。它不能提供与本任务整串/安装件粒度一致的独立材质验证。

没有改写原始数据，也没有把 polymer 改名为 porcelain。标签审计 JSON · 两张原图对照 · 官方发布页

导出全部27张英国图的补标任务：包含20张监督模型空输出图，需逐张补漏；机器候选不是人工参考，材质字段为空。它们只能用于后续开发，新的正式评估还需另留独立资产。补标规范与审核要求

实验、指标和数据使用边界

40轮、1280输入、batch 8、AdamW、FP32、seed 17。只使用开发集选择最佳权重，不调评估阈值、不复用旧英国holdout。开放词汇提示词固定为 utility pole / crossarm / insulator，没有在新评估图上搜索提示词。

每类框匹配必须同时满足类别正确和IoU阈值。AP采用101点插值、IoU=.50:.95、全部标注尺寸、每图最多300候选，不是EPRI官方榜单指标。开放词汇基座保留原分割架构，但本实验只评分框；监督适配使用检测头。

线路分组来自发布者文件名，不等于额外核实了每个物理资产。该样本训练/评估没有完全无目标图，不能证明非杆图过滤能力。公开预训练数据是否包含这些来源未知。类别显示开关只改变可视化，不改变整图或总体指标。
