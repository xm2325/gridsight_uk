Pipeline

Two material approaches, one set of crops.

Automatic insulator proposalsNative-resolution crop + contextFrozen SigLIP2 embeddingsMaterial candidate / unknown

Image references: normalised class prototypes from published training labels, balanced by source image. Text prompts: glass, porcelain, polymer and non-insulator alternatives. SigLIP2 is frozen. The image-reference method returns unknown for crop disagreement, insufficient pixels or a small cosine margin. The text diagnostic shows the top class only when both crop views agree; it is not a verified material decision.

The two adapted detector baselines completed locally before the switch to Roihu; Grounding DINO and all material embeddings ran on Roihu. Changing display filters does not rerun models.

What this does not establish

Useful evidence, bounded claims.

The dataset covers a narrow substation setting and may contain nearby views of the same equipment. There is just one porcelain reference image and one porcelain-containing demo image. This is not an independently sampled benchmark.

Porcelain source polygons outline individual sheds/discs, while many glass labels outline strings. Derived unions are used only for reference support, never as publisher target instances. No reliable material accuracy or cross-material mAP is claimed.

Steelwork, pole and pole-top are not labelled in this material demo. Their current UK hypotheses remain in the separate capability review; a geometric pole-top region is not a verified component detector.
